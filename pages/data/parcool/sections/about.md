{{section: ParCool}}

<center><em>A Minecraft Mod for more Cool actions like Parkour</em></center>

Adds many additional movement and acrobat in Minecraft!! Now you can easily get over tall obstacles, vault over fences, go through narrow spaces quickly, and more.

Since v4.0, ParCool also has *Skilltree* system! Please learn many features of this mod one by one.
**Of course**, it's possible to disable skilltree if you don't need it. For details, please read [FAQ](https://github.com/alRex-U/ParCool/wiki/faq), or request to your server manager.
