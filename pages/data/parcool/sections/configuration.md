{{section: ⚙️ Configuration}}

ParCool configurations are separated into following files.

- `{.minecraft}/config/parcool-client.toml`
- `{.minecraft}/config/parcool-animation.toml`
- `{.minecraft}/saves/{world}/serverconfig/parcool-server.toml`
- `{.minecraft-server}/world/serverconfig/parcool-server.toml`

Some of these configs are available from in-game setting! Please try to press *Alt+P* key while playing.
